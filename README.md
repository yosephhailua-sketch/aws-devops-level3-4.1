# DevOps Starter Pack Deluxe Edition

AWS DevOps Level 3 – Iteration 2 project.

## Technologies

- Terraform
- AWS EC2
- Amazon Linux 2023
- Cloud-init
- Git and GitHub
- Nginx

## Deployment

Terraform creates the EC2 instance and installs Git and Nginx through `user-data.web.sh`.

The website is stored in `html/index.html`.
